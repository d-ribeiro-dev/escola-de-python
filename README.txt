ESCOLA DE PYTHON — PRIMEIRA VERSÃO

COMO ABRIR
1. Extraia o arquivo ZIP para uma pasta.
2. Abra a pasta escola-python.
3. Dê dois cliques em index.html para abrir no navegador.

O QUE JÁ FUNCIONA
- Prova objetiva com 10 questões sobre variáveis, funções nativas, operadores e strings.
- Campo de justificativa em cada questão.
- Revisão livre antes da entrega.
- Entrega definitiva por tentativa.
- Nota objetiva de 0 a 10 e correção comentada.
- Relatório copiável com respostas e justificativas para análise pedagógica no ChatGPT.
- Histórico local no navegador.
- Recuperação com questões alternativas, priorizando os assuntos em que houve erro.

DADOS E LIMITES
- O histórico fica no armazenamento local do navegador (localStorage), neste dispositivo e navegador.
- Limpar os dados do navegador pode apagar o histórico.
- A análise das justificativas não é automática: copie o relatório e envie na conversa para receber a análise pedagógica.
- Esta versão não usa servidor, login, banco de dados remoto ou API paga.
- A imagem da personagem é um recorte da arte de referência do Laboratório Criativo, sem redesenhar a personagem.
